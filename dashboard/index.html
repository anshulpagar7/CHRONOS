What it is

A scheduler that behaves like the real thing.

Jobs arrive with priorities, deadlines, and CPU/memory requirements. Workers advertise capacity and heartbeat their liveness. The scheduler decides who runs what, when — and keeps deciding correctly when workers die mid-job.

Single-threaded actor core

One scheduler thread owns all state; everything else reaches it through a command queue. run_once(now) is the entire scheduling iteration — which makes races structurally impossible and the whole engine testable in a loop.

Resource-aware dispatch

Jobs declare CPU and memory; workers publish free capacity. A bounded skip-scan finds the best job that actually fits, instead of head-of-line blocking on one oversized task.

Crash detection & rescue

Missed heartbeats past the lease window mark a worker dead. Jobs it was running are rescued back to the queue and re-dispatched elsewhere — proven by a chaos test that kills a live worker mid-job.

Backfill reservations

When a large job is repeatedly jumped by smaller ones, the scheduler freezes capacity on the biggest capable worker until it can run — Slurm's answer to starvation, in about a hundred lines.

Deterministic simulator

The production scheduler driven on a simulated clock: 10,000 jobs and twelve minutes of simulated time in about seven seconds — bit-identical for a given seed.

Zero dependencies

Standard library only — including the JSON parser, HTTP server, and this page. Clean builds under Debug, Release, ASan+UBSan, and TSan, all with -Werror.

The state machine

Every job takes one legal path.

Eight states, enforced transitions, and a full history per job. Illegal moves are rejected at the store — which is how a stale report from a worker presumed dead simply bounces off instead of corrupting state.

Evidence

Four policies, one identical workload.

10,000 jobs at ~88% cluster utilization, replayed bit-for-bit under each policy. The result reproduces classical scheduling theory on running code: FIFO is fairest but slowest at the median; Priority starves its tail; EDF minimizes deadline misses; Composite takes the best median while matching EDF.
